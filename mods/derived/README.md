# Derived Mods

此目录只存放基于其他作者 mod 修改、优化或扩展后的个人版本。

每个子目录都必须包含：

- `README.md`：功能、前置 mod、上游地址、本地修改、更新方式和发布状态；
- `metadata.yaml`：上游版本、同步信息、本地修改摘要和发布信息；
- `references/`：上游 mod 描述、更新记录和评论区的带来源摘要；
- CK3 mod 文件。

更新时先获取上游快照，再合并本地修改；发布前必须获得用户明确要求，并遵守原作者许可和 Steam 发布规则。

完成会影响 CK3 游戏内容的修改后，按照根目录 `AGENTS.md` 自动部署到本机 Steam 库的 `steamapps/common/Crusader Kings III/mod/`；仅修改说明、元数据或引用摘要时不部署。
